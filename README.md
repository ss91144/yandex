# GPU-парки OpenAI/Anthropic и маржа Sail Research по GLM-5.2

Тестовое задание: два one-slide ответа для CTO/руководителя, плюс воспроизводимый расчёт.
Данные собраны и расчёты выполнены 28 августа – 1 сентября 2026.

## Что здесь

| Файл | Что это |
|---|---|
| `analysis.ipynb` | Главный файл. Данные, источники, расчёт себестоимости и маржи, sensitivity-анализ, генерация слайдов — всё в одном notebook с пояснениями и выполненными ячейками. **Начните отсюда.** |
| `slides.pdf` | Готовый результат — 2 слайда (16:9), по одному на каждый вопрос. |

| `make_slides.py` | Рендерит `slides.pdf` из чисел в `calcs.py` (matplotlib). |
| `requirements.txt` | `matplotlib`, `numpy`, `pandas`. |

## Как запустить

```bash
pip install -r requirements.txt
python3 calcs.py        # печатает все ключевые числа в консоль
python3 make_slides.py  # пересобирает slides.pdf в текущей папке
```

Либо просто открыть `analysis.ipynb` — там то же самое, но с объяснениями хода мысли и промежуточными таблицами (pandas).

## Методология коротко

**Слайд 1 (GPU-парки).** Ни OpenAI, ни Anthropic не публикуют точные цифры. Использованы: собственные публичные заявления (Altman), независимые datacenter-трекеры (flopper.io), объявленная мощность по контрактам Anthropic–Google/Broadcom (переведена в GPU-эквивалент через ~700 Вт/ускоритель — грубое допущение, явно отмечено). Train/inference split — по отраслевым моделям (Epoch AI) и одной вторичной оценке специально по Anthropic (Lambda Finance, помечена как менее надёжная).

**Слайд 2 (маржа Sail Research).** Bottom-up GPU-TCO модель: `FLOPs/токен ≈ 2 × активные_параметры` (744B total / ~40B active MoE), узел 8×H200 (официальный рецепт деплоя vLLM), себестоимость = GPU-часы × $/GPU-час / MFU × overhead-множитель. Три сценария (bear/base/bull) по MFU (15–40%), цене GPU-часа ($2–5) и overhead (1.5×–5×). Калибровка дополнительно учитывает:
- кто такая Sail Research (венчурный стартап, $80M, позиционируется как throughput/efficiency-инфраструктура для агентов, публично заявляет о высокой утилизации фермы);
- сверку цены Sail с официальной ценой создателя модели (Z.ai, $1.40/$4.40) и с самым дешёвым наблюдаемым ресейлером (OpenRouter, ~$0.49/$1.56).

Все источники — в комментариях `calcs.py` и в подписях к слайдам.

## Ограничения

Подробно — в последней ячейке `analysis.ipynb`. Коротко: все внешние цифры — публичные оценки, не раскрытые компаниями данные; себестоимость Sail Research не подтверждена независимо, только откалибрована по их собственным публичным заявлениям.
